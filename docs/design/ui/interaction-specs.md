## 1. 全局交互规范

### 1.1 页面转场动效

| 转场类型 | 动效 | 时长 | 缓动函数 | 适用场景 |
|----------|------|------|----------|----------|
| Push（推入） | 新页面从右侧滑入，当前页面左移 | 300ms | `ease-out` | Tab页 → 子页面（如首页→AI喵相学） |
| Pop（返回） | 当前页面右滑退出，上一页面左移回位 | 200ms | `ease-in` | 子页面返回上级页面 |
| Modal（底部弹出） | 从底部滑入，背景加遮罩 | 250ms | `ease-out` | 反应弹窗、ActionSheet、分享面板 |
| Fade（淡入淡出） | 透明度 0→1 | 200ms | `ease-in-out` | Tab 页之间切换 |
| None（无动画） | 直接替换 | 0ms | - | 页面内 Tab 切换（手速榜↔颜值榜） |

**规则**:
- Tab 页之间切换使用 Fade，不使用 Push/Pop
- 同级子页面之间跳转使用 Push（如诊断单→分享海报）
- 弹窗类统一使用 Modal + 遮罩 `rgba(0,0,0,0.6)`
- 返回操作统一使用 Pop，支持手势返回

### 1.2 手势操作

| 手势 | 操作 | 适用范围 | 说明 |
|------|------|----------|------|
| 左滑返回 | 从屏幕左边缘右滑 | 所有子页面 | 等同点击返回按钮，触发 Pop 转场 |
| 下拉刷新 | 下拉页面顶部 | 首页、档案、排行榜 | 猫爪踩奶加载动画，300ms 回弹 |
| 上滑加载 | 滑动到页面底部 | 排行榜列表、档案记录列表 | 触底自动加载下一页 |
| 左右滑动 | 水平滑动 | 听力统考分类标签、排行榜 Tab | 切换分类/Tab |
| 长按 | 长按元素 | 分享海报预览 | 保存图片到相册 |

**禁止手势**:
- 爪速挑战游戏中禁用左滑返回（防止误触退出）
- CBTI 答题过程中禁用左滑返回（需弹窗确认）

### 1.3 加载状态规范

| 场景 | 加载方式 | 视觉表现 | 超时处理 |
|------|----------|----------|----------|
| 首次进入页面 | 骨架屏 | 灰色占位块 + 渐变闪烁动画 1500ms | 5s 后显示重试 |
| 下拉刷新 | 顶部加载动画 | 猫爪踩奶动画 | 10s 后自动收起 |
| 照片上传 | 进度条 | 珊瑚渐变进度条 + 百分比 | 30s 超时提示 |
| AI 扫描 | 全屏动画 | 扫描线 + 标注点 + 检测项列表 | 15s 超时重试 |
| 说明书生成 | 全屏过渡页 | 猫爪动画 + 进度条 + 趣味冷知识 | 20s 超时重试 |
| 列表加载更多 | 底部指示器 | 旋转加载图标 + "加载中..." | 5s 后显示重试 |
| 按钮操作 | 按钮内加载 | 按钮文字替换为旋转图标，禁用点击 | 10s 后恢复可点击 |

### 1.4 错误提示规范

| 错误类型 | 提示方式 | 视觉表现 | 操作 |
|----------|----------|----------|------|
| 网络断开 | 全屏空态 | 猫咪睡觉插画 + "网络开小差了" | 重试按钮 |
| 请求超时 | Toast 提示 | 底部 Toast "请求超时，请重试" | 自动消失 1.5s |
| 上传失败 | 弹窗 | Dialog "照片上传失败" | 重试 / 取消 |
| 权限拒绝 | 引导弹窗 | Dialog + 引导文案 | 去设置 / 取消 |
| 数据为空 | 页面空态 | 插画 + 引导文案 + 操作按钮 | 引导用户完成前置操作 |
| 服务异常 | Toast 提示 | "服务器繁忙，请稍后再试" | 自动消失 1.5s |
| 表单校验 | 行内提示 | 输入框下方红色文字 `#FF3B30` | 实时校验 |

### 1.5 震动反馈规范（Haptic Feedback）

| 场景 | 震动类型 | 强度 | API |
|------|----------|------|-----|
| 选择 CBTI 答案 | Light Impact | 轻 | `wx.vibrateShort({type: 'light'})` |
| 爪速挑战命中目标 | Medium Impact | 中 | `wx.vibrateShort({type: 'medium'})` |
| 爪速挑战连击 Combo | Heavy Impact | 重 | `wx.vibrateShort({type: 'heavy'})` |
| 生成结果完成 | Success Notification | 轻 | `wx.vibrateShort({type: 'light'})` |
| 操作失败/错误 | Error Notification | 中 | `wx.vibrateShort({type: 'medium'})` |
| 下拉刷新触发 | Selection | 轻 | `wx.vibrateShort({type: 'light'})` |
| 听力统考选择反应 | Light Impact | 轻 | `wx.vibrateShort({type: 'light'})` |

### 1.6 Toast 与反馈规范

| 反馈类型 | 显示时长 | 位置 | 示例 |
|----------|----------|------|------|
| 成功 Toast | 1500ms | 屏幕中央 | "保存成功" ✓ |
| 错误 Toast | 2000ms | 屏幕中央 | "操作失败" ✗ |
| 信息 Toast | 1500ms | 屏幕中央 | "已复制到剪贴板" |
| 加载 Toast | 跟随操作 | 屏幕中央 | "加载中..." + 旋转图标 |

#### 详细步骤

### 3.3 喵语听力完整流程

```
首页 ──Push──→ 喵语听力统考 ──完成测试──→ 听觉雷达图结果 ──Push──→ 分享海报
                    │                           │
                    │                           ├──→ 重新测试（返回听力统考）
                    │                           └──→ 首页（返回）

```

#### 详细步骤

| 步骤 | 用户操作 | 系统响应 | 反馈 |
|------|----------|----------|------|
| 1 | 进入听力统考 | 默认显示"召唤系"分类 | Push 300ms |
| 2 | 选择分类标签 | 切换声音卡片列表 | 内容切换 200ms |
| 3 | 点击声音卡片 | 播放声音 | 波形动画 |
| 4 | 播放 2-3s 后 | 弹出反应弹窗 | Modal 250ms |
| 5 | 选择猫咪反应 | 记录数据 + 关闭弹窗 | 震动(Light) + Toast 标签 |

| 9 | 查看雷达图 | 展开动画 | 800ms 展开 |

#### 声音播放规则
- 同一时间只能播放一个声音
- 播放新声音时自动停止上一个
- 声音播放完毕后如未弹窗，手动触发弹窗
- 已测试的声音可重新播放和重新记录反应

#### 详细步骤

| 8b | 分享战绩 | 生成海报 | Push 300ms |

#### 游戏交互细节
- 目标运动：贝塞尔曲线不规则运动，速度随时间递增
- 命中特效：目标位置爆炸粒子效果 200ms
- Combo 特效：屏幕边缘闪光 + 中央 Combo 数字放大
- 时间到特效：屏幕白色闪光 → 渐暗 → 结算卡片
