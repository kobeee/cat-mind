# 喵星说明书 - 设计系统规范

> 微信小程序 UI 设计系统 v1.0
> 最后更新: 2026-02-12

---

## 1. 设计理念与风格定义

### 1.1 设计哲学

喵星说明书采用 **"多巴胺科技风 × iOS 精致感"** 的混合设计语言，在微信小程序生态中打造兼具趣味性与专业感的视觉体验。

**核心关键词**: 温暖、活力、精致、有趣

### 1.2 风格体系

项目包含两套视觉风格，根据页面功能场景切换：

#### 浅色模式（主风格）
- **适用页面**: 首页、AI喵相学、CBTI测试、听力统考、双猫匹配、档案、排行榜、我的
- **背景**: 奶油色渐变 `#FAF9F7 → #F8F7F5`
- **卡片**: 纯白 `#FFFFFF`，柔和阴影
- **强调色**: 珊瑚渐变 `#FF8A65 → #FF6B6B`
- **气质**: 温暖、亲和、轻松

#### 深色模式（工业档案风）
- **适用页面**: 喵星说明书（结果页）、爪速大挑战
- **背景**: 深黑 `#0D0D0F`
- **卡片**: 深灰渐变 `#1C1C1E → #252528`，白色细边框
- **强调色**: 活力橙 `#F97316`、香槟金 `#FFD166`
- **气质**: 神秘、科技、档案感

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 友好礼貌 | 避免过度设计，突出重点，减少认知负担 |
| 清晰明确 | 信息层级分明，操作路径清晰，反馈及时 |
| 便捷优雅 | 减少操作步骤，提供快捷入口，优雅处理异常 |
| 统一稳定 | 视觉与交互一致，符合用户认知，避免突兀变化 |

## 2. 颜色系统
### 2.1 品牌色

品牌色是产品视觉识别的核心，贯穿所有页面和交互。

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `coral-primary` | `#FF7A50` | 品牌主色，核心按钮、重要强调 |
| `coral-secondary` | `#FF6B6B` | 品牌辅色，渐变终点、次要强调 |
| `coral-gradient-start` | `#FF8A65` | 主按钮渐变起点 |
| `coral-gradient-end` | `#FF6B6B` | 主按钮渐变终点 |
| `glow-coral` | `#FF7A5026` | 珊瑚色光晕（15%透明度），按钮阴影 |

**品牌渐变**:
```css
/* 主渐变 - 用于主按钮、Hero区域 */
background: linear-gradient(135deg, #FF8A65, #FF6B6B);
```

### 2.2 功能色

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `accent-orange` | `#F97316` | 活力橙，深色页面强调、标签高亮 |
| `accent-primary` | `#C2410C` | 深橙，深色页面主强调 |
| `accent-yellow` | `#FBBF24` / `#FF9500` | 金黄，等级标识、徽章、提示 |
| `champagne-gold` | `#FFD166` | 香槟金，深色页面装饰、高级感元素 |
| `success` | `#34C759` | 成功状态、正确反馈 |
| `danger` | `#FF3B30` | 危险操作、错误提示、警告 |

### 2.3 中性色

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `ink-black` | `#1A1A1A` | 最深文字色，大标题 |
| `text-primary` | `#2D2D2D` | 主文字（浅色页面） |
| `text-secondary` | `#78716C` | 次要文字、描述信息 |
| `text-tertiary` | `#8E8E93` | 辅助文字、占位符 |
| `gray-primary` | `#6B7280` | 图标默认色、次要元素 |
| `gray-secondary` | `#9CA3AF` | 禁用状态、弱化信息 |
| `gray-tertiary` | `#D1D5DB` | 分割线、边框 |

### 2.4 背景色

#### 浅色背景

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `bg-cream` | `#FAF9F7` | 奶油色页面背景（主背景） |
| `bg-primary` | `#FAF9F7` | 等同 bg-cream，语义化别名 |
| `bg-gray` | `#F5F5F7` | 苹果风格浅灰背景 |
| `bg-pure` | `#FFFFFF` | 纯白背景 |
| `bg-white` | `#FFFFFF` | 卡片背景、浮层背景 |
| `bg-surface` | `#E7E5E4` | 表面色，输入框背景、分隔区域 |

#### 深色背景

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `bg-deep` | `#0D0D0F` | 深色页面主背景 |
| `bg-dark` | `#2D2D2D` / `#1C1C1E` | 深色卡片背景 |
| `bg-elevated-dark` | `#2C2C2E` | 深色浮起层背景 |
| `bg-surface-dark` | `#1C1C1E` | 深色表面色 |

### 2.5 颜色使用规则

1. **浅色页面**: 背景用 `bg-cream`，卡片用 `bg-white`，文字用 `text-primary` / `text-secondary`
2. **深色页面**: 背景用 `bg-deep`，卡片用渐变 `#1C1C1E → #252528`，文字用 `#FFFFFF` / `rgba(255,255,255,0.7)`
3. **按钮**: 主按钮用珊瑚渐变，深色页面用 `accent-orange`
4. **禁止**: 不要在浅色背景上使用深色背景色，反之亦然

## 4. 间距系统
基于 4px 网格系统，确保所有间距为 4 的倍数。

### 4.1 基础间距 Token

| Token | 值 | 用途 |
|-------|-----|------|
| `space-1` | 4px | 图标内边距、紧凑间隙 |
| `space-2` | 8px | 小间隙、行内元素间距 |
| `space-3` | 12px | 按钮内边距、紧凑列表间距 |
| `space-4` | 16px | 卡片内边距（标准）、页面水平边距 |
| `space-5` | 20px | 区块内边距、卡片大内边距 |
| `space-6` | 24px | 大间隙、区块间距 |
| `space-8` | 32px | 区块间距（大） |
| `space-10` | 40px | 大区块间距 |
| `space-12` | 48px | 页面顶部/底部留白 |

### 4.2 页面级间距

| 位置 | 值 | 说明 |
|------|-----|------|
| 页面水平边距 | 16px | 左右安全边距 |
| 页面顶部留白 | 状态栏 + 导航栏 | iOS: 44px + 44px = 88px |
| 页面底部留白 | TabBar 高度 | 84px（含安全区） |
| 卡片间距 | 12-16px | 卡片之间的垂直间距 |
| 区块间距 | 24-32px | 不同功能区块之间 |

### 4.3 组件内间距

| 组件 | 内边距 | 说明 |
|------|--------|------|
| 标准卡片 | 16px | 四周均匀 |
| 大卡片 | 20px | 功能卡片、Hero 区域 |
| 按钮 | 0 24px | 水平内边距 |
| 输入框 | 0 12px | 水平内边距 |
| 列表项 | 12px 16px | 垂直 + 水平 |
| 标签 | 4px 8px | 紧凑内边距 |

## 5. 圆角系统
5 个等级的圆角系统，从紧凑到圆润递进。

### 5.1 圆角 Token

| Token | 值 | 用途 | 示例 |
|-------|-----|------|------|
| `radius-xs` | 4px | 标签、徽章 | Tag、Badge |
| `radius-sm` | 8px | 按钮、输入框 | 标准按钮、搜索框 |
| `radius-md` | 12px | 小卡片、列表项 | 导航返回按钮、列表卡片 |
| `radius-lg` | 16px | 标准卡片、弹窗 | 功能卡片、对话框 |
| `radius-xl` | 20-24px | 大卡片、Hero 区域 | 首页功能卡片、结果卡片 |
| `radius-full` | 999px | 圆形、胶囊形 | 头像、Pill 按钮、Tab 容器 |

### 5.2 圆角使用规则

1. **卡片**: 标准用 `radius-lg`(16px)，大卡片用 `radius-xl`(20-24px)
2. **按钮**: 标准用 `radius-sm`(8px)，主按钮用 `radius-lg`(16px)，Pill 用 `radius-full`
3. **输入框**: 统一用 `radius-sm`(8px)
4. **弹窗**: 统一用 `radius-lg`(16px)
5. **Tab 容器**: 用 `radius-full`(26px) 实现胶囊效果
6. **深色卡片**: 与浅色卡片保持一致的圆角值

## 6. 阴影系统

### 6.1 阴影层级

| 层级 | 阴影值 | 用途 |
|------|--------|------|
| 无阴影 | `none` | 扁平元素、深色页面内元素 |
| 轻阴影 | `0 2px 4px rgba(0,0,0,0.04)` | 轻微浮起、列表项 |
| 标准阴影 | `0 4px 12px rgba(0,0,0,0.06)` | 卡片、按钮悬浮 |
| 强阴影 | `0 8px 16px rgba(0,0,0,0.08)` | 弹窗、浮层、ActionSheet |

### 6.2 特殊阴影

| 名称 | 阴影值 | 用途 |
|------|--------|------|
| 按钮阴影 | `0 4px 12px #FF7A5026` | 珊瑚色主按钮光晕 |
| 卡片阴影 | `0 4px 12px rgba(0,0,0,0.06)` | 标准功能卡片 |
| Tab栏阴影 | `0 -1px 4px rgba(0,0,0,0.04)` | 底部 Tab 栏顶部阴影 |
| 深色卡片边框 | `1px solid rgba(255,255,255,0.08)` | 替代阴影，深色页面卡片 |

### 6.3 阴影使用规则

1. **浅色页面**: 使用标准阴影系统
2. **深色页面**: 不使用阴影，改用白色半透明边框 `rgba(255,255,255,0.08)` 区分层级
3. **按钮**: 主按钮使用品牌色光晕阴影，次按钮使用标准阴影
4. **弹窗**: 使用强阴影 + 遮罩层 `rgba(0,0,0,0.6)`

## 8. 页面模板
### 8.1 浅色 Tab 页面（首页、排行榜、档案、我的）

```
结构:
├── 状态栏 (44px, 透明)
├── 页面内容区 (可滚动)
```

## 9. 图标规范

### 9.1 图标库

- **主图标库**: Material Symbols Rounded
- **风格**: Rounded（圆角风格），与整体设计语言一致
- **备选**: SF Symbols（iOS 原生场景）

### 9.2 图标尺寸

| 场景 | 尺寸 | 用途 |
|------|------|------|
| 导航图标 | 24px | 返回、关闭、菜单 |
| Tab 图标 | 24px | 底部 Tab 栏 |
| 功能图标 | 24px | 列表项、操作按钮 |
| 大图标 | 32-40px | 功能卡片、空状态 |
| 装饰图标 | 48-64px | Hero 区域、引导页 |

### 9.3 图标颜色

| 场景 | 颜色 |
|------|------|
| 默认 | `$gray-primary` (#6B7280) |
| 选中/激活 | `$coral-primary` (#FF7A50) |
| 深色页面 | `#FFFFFF` 或 `$accent-orange` |
| 禁用 | `$gray-secondary` (#9CA3AF) |

### 9.4 图标使用规则

1. 保持图标风格统一，全部使用 Rounded 变体
2. 图标与文字搭配时，间距为 8px
3. 可点击图标的触摸区域不小于 44×44px
4. 深色页面图标使用白色或强调色，不使用灰色

## 10. 动效规范
### 10.1 转场动画

| 动画类型 | 时长 | 缓动函数 | 用途 |
|----------|------|----------|------|
| 页面进入 | 300ms | `ease-out` | 新页面从右侧滑入 |
| 页面退出 | 200ms | `ease-in` | 页面向右滑出返回 |
| 弹窗出现 | 200ms | `ease-out` | 弹窗从底部弹起或淡入 |
| 弹窗消失 | 150ms | `ease-in` | 弹窗向下滑出或淡出 |
| Tab 切换 | 200ms | `ease-in-out` | Tab 内容切换 |

### 10.2 交互反馈

| 交互类型 | 时长 | 效果 |
|----------|------|------|
| 按钮按下 | 100ms | 透明度 → 0.8 或缩放 → 0.98 |
| 列表项点击 | 150ms | 背景色 → `rgba(0,0,0,0.05)` |
| 卡片点击 | 200ms | 缩放 → 0.98 |
| 输入框聚焦 | 150ms | 边框色过渡到 `$coral-primary` |
| 开关切换 | 200ms | 滑块平移 + 颜色过渡 |

### 10.3 加载动画

| 类型 | 时长 | 效果 |
|------|------|------|
| 旋转加载 | 1000ms | `linear infinite` 旋转 |
| 骨架屏 | 1500ms | 渐变闪烁 `ease-in-out infinite` |
| 进度条 | 跟随进度 | 宽度过渡 `ease-out` |
| 下拉刷新 | 300ms | 回弹动画 `ease-out` |

### 10.4 动效原则

1. **克制**: 动效服务于功能，不做纯装饰性动画
2. **自然**: 使用符合物理直觉的缓动曲线
3. **快速**: 交互反馈不超过 200ms，转场不超过 300ms
4. **一致**: 相同类型的交互使用相同的动效参数
