
# 喵星说明书 (Meow Manual) - 微信小程序原型设计

## 设计原则

### 1. 画布布局规范
- **所有页面横向排列**在一行内
- 页面间距：100px
- 第一个页面位置：(0, 0)
- 每个页面尺寸：402px × 874px (iPhone 14 Pro 标准尺寸)

### 2. 设计风格 - "多巴胺科技风"

**配色方案：**
- 主背景：#FFFFFF (纯白)
- 卡片背景：#F5F5F7 (苹果风格浅灰)
- 深色卡片：#1C1C1E (深色模式背景)
- 主强调色：#FF6B35 (活力橙)
- 次强调色：#FF9500 (亮橙)
- 成功色：#34C759 (绿)
- 警告色：#FF3B30 (红)
- 主文字：#000000 (黑)
- 次文字：#6E6E73 (灰)
- 辅助文字：#8E8E93 (浅灰)

**字体规范：**
- 标题：SF Pro Display / PingFang SC, 粗体
- 正文：SF Pro Text / PingFang SC, 常规
- 大标题：28-32px, 粗体
- 小标题：20-24px, 中等
- 正文：16-17px, 常规
- 辅助文字：13-14px, 常规

**圆角规范：**
- 大卡片：20px
- 小卡片/按钮：12px
- 标签：8px
- 全圆角：100px (pill shape)

**间距规范：**
- 页面边距：20px
- 卡片内边距：20px
- 元素间距：16px
- 小组件间距：8px

### 3. 页面列表

1. **首页 (Home)** - 位置 (0, 0)
2. **AI喵相学 (AI Face)** - 位置 (502, 0)
3. **CBTI测试 (CBTI Test)** - 位置 (1004, 0)
4. **喵星说明书 (Manual)** - 位置 (1506, 0)
5. **听力统考 (Hearing)** - 位置 (2008, 0)
6. **爪速挑战 (APM Game)** - 位置 (2510, 0)
7. **双猫匹配 (Match)** - 位置 (3012, 0)

### 4. 设计要点

- 所有页面统一使用 iOS 风格设计
- 保持视觉层次清晰
- 使用适当的阴影和留白
- 图标使用 SF Symbols 风格
- 避免过度装饰，保持简洁
- 确保文字清晰可读
- 按钮和交互元素要有明显的视觉反馈
