# 小程序研发计划（一次性交付）

## 1. 执行顺序（固定）

1. 初始化工程骨架（路由、工具、mock、组件）
2. 实现 4 个 Tab 页面（首页/档案/排行/我的）
3. 实现 AI 主链路页面（AI喵相学 → 扫描中 → 诊断单 → CBTI → 生成中 → 说明书）
4. 实现实验室链路页面（听力统考、雷达图；爪速准备、挑战）
5. 实现社交链路页面（双猫匹配、邀请、海报）
6. weapp-dev 自动化回归
7. 记录 CHANGELOG

## 2. Mock 数据策略

- 所有数据源来自 `mock/data.ts`
- 所有“用户动作结果”存储于 `wx.setStorageSync`
- 页面读取优先级：`storage > mock default`

## 3. 验证清单

### 3.1 路由验证

- 首页 5 个功能入口全部可达
- 过渡页自动跳转生效
- Tab 互跳不产生异常返回栈

### 3.2 功能验证

- CBTI 能完成 20 题并产出说明书
- 听力测试可记录反应并进入雷达图
- 爪速挑战倒计时结束后出现结算
- 分享页支持保存/发送动作反馈

### 3.3 视觉验证

- 关键页与 `cat.pen` 对照截图检查：
  - 首页
  - AI喵相学
  - CBTI测试
  - 说明书
  - 听力测试
  - 爪速挑战
  - 双猫匹配
  - 档案/排行/我的

## 4. 风险与处理

1. 无后端接口：全部 mock 化，先保证前端流程闭环。
2. 自动化连接失败：先确保代码完整交付，再转人工验收。
3. 视觉细节偏差：优先还原布局与层级，再微调颜色与间距。
