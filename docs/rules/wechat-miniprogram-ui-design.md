# 微信小程序 UI 设计规范

> 基于 WeUI 官方设计规范整理
> 版本: 1.0
> 适用: 喵星说明书小程序设计

---

## 1. 屏幕尺寸

- **标准宽度**: 750rpx (自适应)
- **页面高度**: 自动适应设备
- **安全区**: 底部 TabBar 高度约 100rpx
- **状态栏**: iOS 44px / Android 25px
- **导航栏**: 44px

---

## 2. 配色方案 (WeUI 标准)

### 2.1 主色调

| 颜色名 | 色值 | 用途 |
|--------|------|------|
| 微信绿 | `#07C160` | 主按钮、成功状态、强调 |
| 活力橙 | `#FF6B35` | 强调色、营销按钮 |
| 警告红 | `#FA5151` | 危险操作、错误提示 |
| 金黄 | `#FFC300` | 提示、徽章、等级 |
| 链接蓝 | `#576B95` | 链接文字 |

### 2.2 中性色

| 颜色名 | 色值 | 用途 |
|--------|------|------|
| 标题黑 | `#000000` | 主要标题、重要文字 |
| 正文深灰 | `#333333` | 正文内容 |
| 次要文字 | `#666666` | 次要信息 |
| 辅助文字 | `#999999` | 辅助说明、占位符 |
| 禁用灰 | `#B2B2B2` | 禁用状态 |
| 边框灰 | `#E5E5E5` | 分割线、边框 |
| 背景灰 | `#F5F5F5` | 页面背景 |
| 纯白 | `#FFFFFF` | 卡片背景、文字 |

## 3. 字体规范

### 3.1 字体栈

```css
/* iOS */
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Helvetica Neue', Arial, sans-serif;

/* Android */
font-family: 'Noto Sans CJK SC', 'Roboto', Arial, sans-serif;
```

### 3.2 字号层级

| 层级 | 大小 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| 大标题 | 20px | 600 | 1.4 | 页面主标题 |
| 标题 | 18px | 600 | 1.4 | 区块标题 |
| 小标题 | 16px | 600 | 1.5 | 卡片标题 |
| 正文 | 16px | 400 | 1.6 | 主要文字 |
| 辅助文字 | 14px | 400 | 1.5 | 描述说明 |
| 小字 | 12px | 400 | 1.4 | 标签、时间 |
| 最小 | 10px | 400 | 1.3 | 角标、徽章 |

## 4. 间距系统

### 4.1 基础间距 (基于 4px 网格)

| 变量名 | 值 | 用途 |
|--------|-----|------|
| space-xs | 4px | 图标内边距、紧凑间距 |
| space-sm | 8px | 小间隙、标签间距 |
| space-md | 12px | 按钮内边距、列表项间隙 |
| space-lg | 16px | 卡片内边距、标准间隙 |
| space-xl | 24px | 区块间距、大间隙 |
| space-2xl | 32px | 大区块间距 |

### 4.2 页面边距

- **页面水平边距**: 16px (小程序标准)
- **安全区边距**: 24px (特殊内容)
- **TabBar 高度**: 100rpx (底部导航)

## 5. 圆角规范

| 元素类型 | 圆角值 | 示例 |
|----------|--------|------|
| 大卡片 | 16px | 内容卡片、弹窗 |
| 小卡片 | 12px | 功能入口、列表项 |
| 按钮 | 8px | 所有按钮 |
| 输入框 | 8px | 表单输入 |
| 标签 | 4px | Tag、Badge |
| 头像 | 50% | 圆形头像 |
| 全圆角 | 999px | Pill 按钮 |

## 6. 阴影规范

| 层级 | 阴影值 | 用途 |
|------|--------|------|
| 无 | none | 扁平设计 |
| 小 | `0 2px 4px rgba(0,0,0,0.04)` | 卡片悬停 |
| 中 | `0 4px 8px rgba(0,0,0,0.06)` | 浮层、卡片 |
| 大 | `0 8px 16px rgba(0,0,0,0.08)` | 弹窗、抽屉 |

## 9. 页面结构

### 9.1 标准页面结构

```
Page (页面)
├── NavigationBar (导航栏)
│   ├── StatusBar (状态栏: 44px iOS / 25px Android)
│   └── TitleBar (标题栏: 44px)
├── Content (内容区)
│   ├── Header (头部)
│   ├── Body (主体)
│   └── Footer (底部)
└── TabBar (底部导航: 100rpx, 可选)
```

### 9.2 页面边距规范

- 内容区左右边距: 16px
- 卡片内边距: 16px
- 区块间距: 24px
- 元素间距: 12px

## 10. 设计原则

### 10.1 微信设计原则

1. **友好礼貌**: 避免过度设计，保持界面清晰
2. **清晰明确**: 信息层级明确，一目了然
3. **便捷优雅**: 减少操作步骤，提供反馈
4. **统一稳定**: 保持视觉和交互一致性

### 10.2 设计建议

- **留白**: 保持适当的留白，让页面呼吸
- **对比**: 使用颜色对比突出重点
- **对齐**: 严格对齐，保持秩序感
- **简洁**: 减少装饰元素，聚焦内容
