## 1. 设计原则

### 1.1 友好礼貌

- 避免过度设计，保持界面清晰
- 突出重点，弱化次要信息
- 减少用户的认知负担

### 1.2 清晰明确

- 信息层级明确，一目了然
- 让用户知道当前位置和可执行操作
- 提供清晰的反馈

### 1.3 便捷优雅

- 减少操作步骤
- 提供快捷入口
- 优雅的错误处理

### 1.4 统一稳定

- 保持视觉和交互一致性
- 符合用户已有认知
- 避免突兀的变化

## 2. 视觉规范

### 2.1 颜色系统

#### 主色调

| 名称 | 色值 | 使用场景 |
|------|------|----------|
| 微信绿 | `#07C160` | 主按钮、成功状态、重要强调 |
| 活力橙 | `#FF9500` | 营销按钮、特殊强调 |
| 警告红 | `#FA5151` | 危险操作、错误提示 |
| 金黄 | `#FFC300` | 提示、徽章、等级标识 |
| 链接蓝 | `#576B95` | 链接文字、可点击文字 |

#### 中性色

| 名称 | 色值 | 使用场景 |
|------|------|----------|
| 标题黑 | `#000000` | 主要标题、重要文字 (透明度 87%) |
| 正文深灰 | `#333333` | 正文内容 |
| 次要文字 | `#666666` | 次要信息 |
| 辅助文字 | `#999999` | 辅助说明、占位符 |
| 禁用灰 | `#B2B2B2` | 禁用状态 |
| 边框灰 | `#E5E5E5` | 分割线、边框 |
| 背景灰 | `#F5F5F5` | 页面背景 |
| 纯白 | `#FFFFFF` | 卡片背景 |

#### 背景色

| 名称 | 色值 | 使用场景 |
|------|------|----------|
| 页面背景 | `#F5F5F5` | 整个页面背景 |
| 卡片背景 | `#FFFFFF` | 卡片、浮层背景 |
| 遮罩层 | `rgba(0,0,0,0.6)` | 弹窗遮罩 |

### 2.2 字体规范

#### 字体栈

```css
/* iOS */
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Helvetica Neue', Arial, sans-serif;

/* Android */
font-family: 'Noto Sans CJK SC', 'Roboto', 'PingFang SC', Arial, sans-serif;
```

#### 字号层级

| 层级 | 大小 | 字重 | 行高 | 字间距 | 用途 |
|------|------|------|------|--------|------|
| 大标题 | 22px | 600 | 1.4 | 0 | 页面主标题 |
| 标题 | 18px | 600 | 1.4 | 0 | 区块标题 |
| 小标题 | 17px | 600 | 1.4 | 0 | 卡片标题 |
| 正文 | 16px | 400 | 1.6 | 0 | 主要文字 |
| 辅助文字 | 14px | 400 | 1.5 | 0 | 描述说明 |
| 小字 | 12px | 400 | 1.4 | 0 | 标签、时间 |

#### 字重规范

| 字重 | 值 | 用途 |
|------|-----|------|
| 常规 | 400 | 正文、描述 |
| 中等 | 500 | 按钮文字、标签 |
| 半粗 | 600 | 标题、强调 |
| 粗体 | 700 | 大标题、价格 |

### 2.3 间距系统

#### 基础间距 (4px 网格)

| 变量名 | 值 | 用途 |
|--------|-----|------|
| space-1 | 4px | 图标内边距 |
| space-2 | 8px | 小间隙 |
| space-3 | 12px | 按钮内边距 |
| space-4 | 16px | 卡片内边距 (标准) |
| space-5 | 20px | 区块内边距 |
| space-6 | 24px | 大间隙 |
| space-8 | 32px | 区块间距 |
| space-10 | 40px | 大区块间距 |
| space-12 | 48px | 页面边距 |

#### 页面边距

- **水平安全边距**: 16px (标准)
- **TabBar 高度**: 100rpx (约 50px)
- **导航栏高度**: 44px
- **状态栏高度**: iOS 44px / Android 25px

### 2.4 圆角规范

| 元素 | 圆角值 | 示例 |
|------|--------|------|
| 大卡片 | 16px | 内容卡片、功能模块 |
| 中卡片 | 12px | 列表项、小卡片 |
| 按钮 | 8px | 所有按钮 |
| 输入框 | 8px | 表单输入 |
| 标签/徽章 | 4px | Tag、Badge |
| 头像 | 50% | 圆形头像 |
| Pill 按钮 | 999px | 圆角按钮 |

### 2.5 阴影规范

| 层级 | 阴影值 | 用途 |
|------|--------|------|
| 无 | none | 扁平设计 |
| 小 | `0 2px 4px rgba(0,0,0,0.04)` | 轻微浮起 |
| 中 | `0 4px 8px rgba(0,0,0,0.06)` | 卡片、按钮 |
| 大 | `0 8px 16px rgba(0,0,0,0.08)` | 弹窗、浮层 |

## 3. 布局规范

### 3.1 页面结构

```
Page (页面)
├── StatusBar (状态栏) - 44px/25px
├── NavigationBar (导航栏) - 44px
│   ├── 返回按钮 (可选)
│   ├── 标题 (居中)
│   └── 操作按钮 (可选)
├── Content (内容区)
│   ├── 轮播/ banner
│   ├── 功能入口
│   ├── 内容列表
│   └── 操作区域
└── TabBar (底部导航) - 100rpx
```

### 3.2 内容区布局

#### 单列布局 (标准)

- 边距: 16px
- 卡片宽度: 100% - 32px
- 间距: 12px

#### 双列布局

- 边距: 16px
- 列间距: 12px
- 每列宽度: (100% - 44px) / 2

#### 网格布局

- 边距: 16px
- 项间距: 8px
- 常见: 4列图标、3列图片

### 3.3 安全区域

- 顶部: 避开状态栏 + 导航栏
- 底部: 避开 TabBar / iPhone X 底部横条
- 左右: 16px 安全边距

## 5. 动效规范

### 5.1 转场动画

| 动画 | 时长 | 缓动函数 | 用途 |
|------|------|----------|------|
| 页面进入 | 300ms | ease-out | 新页面进入 |
| 页面退出 | 200ms | ease-in | 页面返回 |
| 弹窗出现 | 200ms | ease-out | 弹窗展示 |
| 弹窗消失 | 150ms | ease-in | 弹窗关闭 |

### 5.2 交互动画

| 交互 | 时长 | 缓动函数 |
|------|------|----------|
| 按钮点击 | 100ms | ease |
| 列表点击 | 150ms | ease |
| 卡片悬浮 | 200ms | ease-out |
| 输入框聚焦 | 150ms | ease |
| 加载旋转 | 1000ms | linear infinite |

### 5.3 反馈动画

- **按钮按下**: 透明度 0.8 或缩放 0.98
- **列表点击**: 背景色变化 (rgba(0,0,0,0.05))
- **加载状态**: 旋转动画
- **刷新**: 下拉回弹动画

## 6. 适配规范

### 6.1 屏幕适配

- 使用 rpx 单位进行布局
- 基准宽度: 750rpx
- 字体使用 px 保持清晰

### 6.2 设备适配

#### iPhone X 及以上

- 底部增加 34px 安全区
- 顶部状态栏 44px

#### 安卓设备

- 底部无额外安全区
- 顶部状态栏 25px

### 6.3 暗黑模式 (可选)

| 元素 | 亮色模式 | 暗黑模式 |
|------|----------|----------|
| 页面背景 | #F5F5F5 | #111111 |
| 卡片背景 | #FFFFFF | #1C1C1E |
| 主文字 | #000000 | #FFFFFF |
| 次文字 | #666666 | #98989D |
