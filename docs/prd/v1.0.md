【产品设计方案：喵星说明书 (Meow Manual)】

一、 产品概述 (Product Overview)

1.1 产品名称
   - 中文名：喵星说明书
   - 英文名：Meow Manual / CatOS Guide

1.2 Slogan
   - “拒绝玄学，科学破译你家主子的出厂设置。”
   - “全网首款猫咪 BIOS 读取器。”

1.3 核心价值 (Value Proposition)
   - 对用户：不仅是逗猫，更是“懂猫”。通过互动和测试，让铲屎官获得一种“我掌握了猫咪核心数据”的掌控感和炫耀感。
   - 对猫咪：建立数字化档案，长期跟踪情绪与行为。

1.4 目标用户
   - 核心群体：95后/00后年轻铲屎官，重度社交媒体用户（朋友圈/小红书）。
   - 用户画像：把猫当孩子/主子养，热衷于星座/MBTI，喜欢给猫拍照，愿意为“猫咪人设”买单。

二、 产品架构与用户路径 (User Journey)

[ 首次进入 ] -> [ AI 面相速测 (钩子) ] -> [ 生成初级报告 ]
     ↓
[ 深度使用 ] -> [ CBTI 行为测试 (核心) ] -> [ 生成《喵星说明书》 ]
     ↓
[ 日常留存 ] -> [ 每日猫历 (Agent) ] + [ 听力/爪速实验室 (工具) ]

三、 详细功能模块设计 (Feature Specification)

模块一：喵星身份识别中心 (Identity Lab)
*这是流量入口，负责裂变和吸引新用户。*

1. AI 喵相学 (AI Face Reading) - 流量钩子
   - 交互：
     1. 用户上传一张猫咪正脸照。
     2. 界面展示高科技扫描动画（网格线扫描眼睛、耳朵、胡须）。
   - 逻辑（娱乐化）：
     1. 识别花色（如橘色）：输出标签“易胖体质”、“干饭机器”。
     2. 识别瞳孔状态：输出标签“鄙视链顶端”、“看起来不太聪明的亚子”。
   - 产出：一张“喵相诊断单”。
     - 包含：面相评分（如：98分 旺家相）、核心槽点（如：这就一张没受过欺负的脸）。

2. CBTI 深度性格测试 (The Core Test) - 核心留存
   - 交互：基于 Feline Five (猫科五大性格) 的 20 道趣味问卷。
   - 题目设计（拒绝枯燥）：
     - ❌ “它是否活泼？”
     - ✅ “当快递员敲门时，它的反应是：A. 骂骂咧咧冲门口 B. 瞬间移动到床底 C. 毫无波澜继续睡”。
   - 产出：生成终极产品——《猫咪使用说明书》。
     - 视觉风格：工业风/说明书风格（类似宜家说明书）。
     - 内容包含：
       - 【出厂型号】：如“E型社牛猫”、“I型自闭猫”、“霸道总裁猫”。
       - 【性能参数】：粘人度 80% / 攻击力 10% / 智商 (数据丢失)。
       - 【维护指南】：宜：拍屁股；忌：剪指甲。
       - 【质保二维码】：扫码查看该猫详细档案。

模块二：猫咪应激实验室 (Reaction Lab)
*这是工具属性，负责增加用户停留时长和数据丰富度。*

1. 喵语听力统考 (Hearing Test)
   - 定义：不是单纯的播放器，而是一个“听力与性格关联实验”。
   - 声音库分类：
     - 【召唤系】：开罐头声、摇猫粮声。
     - 【挑衅系】：同类打架声、哈气声。
     - 【猎奇系】：鸟叫声、老鼠声。
   - 玩法：
     1. 用户点击播放“打架声”。
     2. 系统立刻弹窗：“主子反应如何？”（A. 飞机耳 B. 炸毛 C. 无视）。
     3. 记录数据：如果选 C，系统判定“听觉过滤系统开启”，性格标签增加“高冷”。
   - 产出：生成《听觉敏感度雷达图》。

2. 爪速大挑战 (APM Challenge)
   - 定义：基于 Canvas 的捉虫小游戏，测试猫咪的反应速度。
   - 玩法：
     - 屏幕出现高对比度的目标（红点/苍蝇/老鼠）。
     - 目标做不规则运动。
     - 记录猫咪爪子触碰屏幕的次数和连击数 (Combo)。
   - 结算页面（炫耀点）：
     - 不显示分数，显示战力值。
     - 文案：“本次测试有效出拳 38 次，击败了全小区 99% 的猫！”
     - 称号：“获得【无影爪宗师】称号”。

模块三：猫历 Agent (Daily Cat Agent)
*这是粘性功能，负责让用户每天都想打开看一眼。*

1. 每日宜忌 (Daily Horoscope)
   - 逻辑：结合【地理位置天气】+【猫咪性格测试结果】+【日期算法】。
   - 呈现：首页顶部卡片，每天自动更新。
   - 示例 Case A（雨天 + 胆小猫）：
     - “今日气压低，您的【怂包型】主子可能电量不足。”
     - 🟢 宜：躲在纸箱里、喂冻干。
     - 🔴 忌：吸尘器、强行抱抱。
   - 示例 Case B（晴天 + 活泼猫）：
     - “今日阳光充足，【跑酷型】引擎预热完成。”
     - 🟢 宜：激光笔消耗电量。
     - 🔴 忌：把水杯放在桌边。

四、 UI/UX 设计风格 (Design Language)

1. 色调与氛围
   - 放弃“冷淡风”或“医院风”。
   - 采用 **“多巴胺科技风”**：高饱和度的暖黄、亮橙搭配深灰背景。营造一种“这是黑科技，但很温馨”的感觉。

2. 交互细节
   - 震动反馈 (Haptic)：用户在点击测试选项、或者猫咪抓到虫子时，手机必须有短促的震动反馈，增加爽感。
   - 加载动画：不要用转圈圈，用“猫爪踩奶”或“猫尾巴摇摆”的动画。

五、 社交与裂变机制 (Growth Strategy)

1. “双猫匹配” (Match Mode)
   - 场景：我有猫，朋友也有猫。
   - 功能：生成海报时，带有一个“测测缘分”的二维码。朋友扫码进入，上传他的猫的数据。
   - 结果：“你家的【霸总猫】与他的【绿茶猫】匹配度为 85%，建议结为亲家。”

2. 排行榜 (Leaderboard)
   - 设立“本周手速榜”和“本周颜值榜”（基于点赞）。
   - 只有生成了“说明书”的用户才能上榜。

六、 商业化预埋 (Monetization)

1. 流量变现（初期）：
   - 激励视频广告：想解锁“隐藏性格标签”或“高级猫叫声”，看 15 秒视频。
   - 结果页底部 Banner。

2. 导购变现（中期）：
   - 在《说明书》的“推荐燃料”一栏，假如建议“喂食冻干”，可以直接挂京东/淘宝联盟的猫零食链接。
   - “您的猫咪不仅是【干饭王】，更需要【高蛋白】，推荐这款...”

七、 迭代计划 (MVP Roadmap)

- v1.0 (MVP)：包含 AI 面相（随机娱乐版）、CBTI 基础问卷、猫叫播放器、结果海报生成。
- v1.1：加入“爪速大挑战”小游戏，优化海报设计。
- v1.2：加入“猫历 Agent”，接入天气数据，实现千猫千面的每日建议。
